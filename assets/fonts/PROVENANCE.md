# Bundled Inter font

NoirGlass includes **Inter Variable** for its interface text. The theme embeds the font in the distributed CSS, so installing the theme does not require a separate font installation or download.

The font comes from [the official Inter project](https://github.com/rsms/inter). The file was downloaded from its master branch; the copy committed in this repository is the source used for NoirGlass builds.

Inter is copyrighted by **The Inter Project Authors** and redistributed under the [SIL Open Font License](OFL.txt). This license applies to the font; the theme's code uses the [MIT License](../../LICENSE).
